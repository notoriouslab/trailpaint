文天祥南逃

1275-1283 正氣留千古

文天祥南逃：景點列表

德祐元年（1275）元軍渡江，南宋殘局如風中殘燭。廬陵書生文天祥散盡家財舉兵勤王，入衛臨安，受命使元軍議和卻遭拘執；脫身後輾轉閩粵，擁立益王、衛王於福州，轉戰汀漳，兵敗空坑、再敗於潮陽五坡嶺被俘。押解經伶仃洋時寫下「人生自古誰無死，留取丹心照汗青」，又親眼見崖山海戰，十萬軍民蹈海，南宋遂亡。北解元大都，囚於燕獄三年，作《正氣歌》明志，拒忽必烈宰相之誘，至元十九年（1283）臘月初九從容就義於柴市，年四十七。全程由故鄉吉安至就義之地，跨越大半個中國，用生命為南宋王朝寫下最後一行墓誌銘。

  1. 1. 廬陵吉安．少年起家 1275–1278

    文天祥，字宋瑞、履善，號文山，南宋端平三年（1236）生於江西廬陵富川（今吉安縣）。幼承庭訓，讀歐陽修、楊邦乂等鄉賢祠像，慨然曰：「沒不俎豆其間，非夫也。」寶祐四年（1256）進士第一，年僅二十。廬陵山水清秀，青原山、贛江在此匯流，是他一生精神的源頭，也是他最後歸葬之地（富田鎮鶩湖大坑）。

  2. 2. 臨安勤王．丞相議和 1275–1278

    德祐元年（1275）正月，元伯顏大軍渡江，謝太后詔天下勤王。文天祥在贛州得詔，痛哭捧詔，散家財招募豪傑、溪峒蠻，得兵三萬入衛臨安。友人勸其勿以烏合之眾撄虎口，他答：「國家養育臣庶三百餘年，一旦有急，徵天下兵無一人一騎入關者，吾深恨於此。」次年正月拜右丞相樞密使，奉命入元營議和，痛斥伯顏「南北兵勢，義在必戰」，被拘北上。

  3. 3. 鎮江脫身．間道歸南 1275–1278

    德祐二年（1276）二月，文天祥被元軍押至鎮江，與同伴杜滸等十二人夜半踰垣脫逃，繞道真州、揚州、通州、海道，備嘗艱險，九死一生。途中「嗚呼哀哉，痛定思痛，痛何如哉」，將逃亡所作詩文編為《指南錄》，取「臣心一片磁針石，不指南方不肯休」之意。此次生還，是他選擇繼續抗元而非殉國的關鍵轉折。

  4. 4. 福州擁立．開府南劍 1275–1278

    德祐二年五月，陸秀夫、陳宜中等擁益王趙昰即位於福州，改元景炎，是為端宗。文天祥輾轉抵福州，拜右丞相，旋以意見不合，自請開督府於南劍州（今福建南平），招兵聚糧，圖恢復。福州烏山明城牆遺址即此時抗元之背景。此時南宋朝廷實已流亡海上，福州是大陸最後的朝堂。

  5. 5. 空坑兵敗．妻女被俘 1275–1278

    景炎二年（1277）八月，文天祥率軍入贛，光復會昌、雩都等縣，聲勢再振。元將李恆以精騎追擊，八月十七於興國空坑大敗宋軍。文天祥妻歐陽夫人、二子、二女皆被俘北去，部將趙時賞以身代死喊「我姓文」，天祥乃得脫。骨肉離散之痛，此後詩作中一再浮現：「痛哉柳女環女」—柳娘、環娘二女皆死途中。

  6. 6. 潮陽五坡嶺．兵敗被俘 1275–1278

    祥興元年（1278）十二月二十，文天祥移屯潮陽海豐五坡嶺（今廣東海豐縣北），方進食，元張弘範部將張弘正率騎突襲。倉卒迎戰，眾潰被執。吞腦子（龍腦香，古人以為可自盡之毒藥）不死。解至潮陽見張弘範，左右命拜，不屈；弘範禮之，與俱入崖山。此役為文天祥武裝抗元之終點，從此只剩囚徒之身，而其氣節反而愈顯。

  1. 1. 伶仃洋．過零丁詩 1278–1283

    祥興二年（1279）正月，張弘範押文天祥經珠江口伶仃洋（今珠海、深圳、香港之間海域），欲脅其書招張世傑降。天祥書所作《過零丁洋》付之：「辛苦遭逢起一經，干戈寥落四周星。山河破碎風飄絮，身世浮沉雨打萍。惶恐灘頭說惶恐，零丁洋裏歎零丁。人生自古誰無死，留取丹心照汗青。」弘範笑曰：「好人，好詩！」遂不復強。此七律是中國士人氣節的千古標竿。

  2. 2. 崖山目擊．宋室蹈海 1278–1283

    祥興二年二月初六，崖山（今廣東江門新會南海中）宋元決戰。張弘範以舟師圍宋，陸秀夫負幼帝昺投海，楊太后及十餘萬軍民隨之蹈海。文天祥在元船上目睹，「痛哭，為之賦詩」，云：「羯來南海上，人死亂如麻。腥浪拍心碎，飆風吹鬢華。」自此江山易色，宋祚絕。他雖苟活，卻已是「別一乾坤」中的亡國之臣。崖門海戰是漢民族歷史的大分水嶺。

  3. 3. 建康（金陵）．北解途中絕食 1278–1283

    祥興二年四月，文天祥自崖山經廣州北解。途中絕食八日不死；過建康（今南京），瞻鐘山、秦淮，作《金陵驛》二首：「草合離宮轉夕暉，孤雲飄泊復何依。山河風景元無異，城郭人民半已非。滿地蘆花和我老，舊家燕子傍誰飛。從今別卻江南路，化作啼鵑帶血歸。」建康是南宋舊日行在，過之如見故國魂魄。

  4. 4. 元大都．燕獄作正氣歌 1278–1283

    至元十六年（1279）十月抵大都，囚兵馬司土室，不見日月者三年。牢房低濕，兼具「水、土、日、火、米、人、穢、瘴」七氣雜侵。至元十八年夏，獄中作《正氣歌》：「天地有正氣，雜然賦流形。下則為河嶽，上則為日星。於人曰浩然，沛乎塞蒼冥。」歷數齊太史簡、晉董狐筆、張良椎、蘇武節等十二忠義故事，以「是氣所磅礴，凜烈萬古存」自期。此歌與《過零丁洋》雙璧，定義了中國士人之「節」。

  5. 5. 丞相祠．勸降不屈 1278–1283

    元世祖忽必烈愛其才，屢遣降臣留夢炎、瀛國公趙㬎、平章阿合馬、丞相孛羅，直至親自召見，許以中書宰相，皆不屈。文天祥見忽必烈長揖不跪，曰：「天祥受宋恩，為宰相，安事二姓？願賜之一死足矣。」忽必烈猶不忍殺，囚之三年。今北京府學胡同 63 號「文丞相祠」，即當年兵馬司獄遺址，明洪武九年（1376）詔建。

  6. 6. 柴市就義．絕命贊 1278–1283

    至元十九年（1283）十二月初九，文天祥就刑於大都柴市口（今北京東城府學胡同西口交道口一帶）。臨刑從容，向南再拜而死，年四十七。衣帶中得絕命贊：「孔曰成仁，孟曰取義，惟其義盡，所以仁至。讀聖賢書，所學何事？而今而後，庶幾無愧。」夫人歐陽氏收屍，見其面如生。明永樂六年建文丞相祠於其殉難地，至今猶存。
