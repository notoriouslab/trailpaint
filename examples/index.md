# 出門走走

> TrailPaint 出門走走：台灣登山步道、古道、親子散步與海外旅行的手繪路線地圖，Story Player 自動播放，或下載 .trailpaint.json 匯入 Editor 改成自己的行程。

URL: https://trailpaint.org/examples/
Parent: https://trailpaint.org/
Language: zh-TW

別人走過的路，點圖就能播放。按「↓ 下載」拿到 `.trailpaint.json`，從 Editor「匯入」改成你自己的行程。
